# Crochet Wiki｜編織知識庫

Crochet Wiki 是一個以鉤針編織為主題的線上知識庫，將零散的編織筆記、材料資訊、針法縮寫與製作步驟，整理成清楚且容易閱讀的教學頁面。

網站採用統一的頁面架構與視覺設計，讓每個編織作品都能以一致的格式呈現，幫助使用者快速查找材料、了解針法，並依照步驟完成作品。

本專案也透過 `AGENTS.md` 建立 AI 開發規範，定義網站的檔案結構、設計風格、內容格式與開發流程。未來只要提供新的編織資料，AI 就能依照既有規範新增教學頁面，讓知識庫持續擴充，同時維持整體網站的一致性。

**專案目標：打造一個容易閱讀、方便查找，並能透過 AI 持續擴充的編織知識平台。**
